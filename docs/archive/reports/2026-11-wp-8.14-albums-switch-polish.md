## What was built

1. **Spacing fixed in the shared `SourceRow`** (the reported bug: the 51 dp
   `SwipeSwitch` track spilled ~3.5 dp past each side of its 44 dp touch box and
   touched the count):
   - The switch's touch box is now
     `max(minTouchTarget, switchTrackWidth)` × `minTouchTarget` = **51 × 44 dp**
     (`SourceRowSwitch` in `ui/components/SourceRow.kt`), so the track fits its
     box instead of spilling toward the count. No new token was needed — the box
     is computed from existing `ComponentSizes.switchTrackWidth` and
     `Sizes.minTouchTarget` (hard rule 3 holds).
   - An `s` gap separates **count → switch** and **switch → chevron**. The
     count→switch gap is its own `Spacer(Modifier.width(s))` node, not a padding
     modifier: padding rides inside the count's semantics bounds, and the FR-37
     layout test measures the real edge-to-edge gap.
   - The chevron's start padding is **conditional** — `s` only when a switch is
     present, `xs` otherwise — so Home and By-month rows (no switch) render
     byte-identically to before.
   - Detekt's 60-line function cap was hit after adding the subtitle branch, so
     the title/subtitle block moved into a private `SourceRowTitle` composable
     (`b30139d`). Pure refactor, no behavior change.

2. **Explainer line on Albums.** Under the header, above the list, shown **every
   time**: "Turn an album on to leave its photos out of Shuffle everything."
   (`SHUFFLE_EXPLAINER` in `AlbumsScreen.kt`, shown in both the loading and the
   list states).

3. **"Not in Shuffle" subtitle.** When an album's switch is on, its row shows
   `Not in Shuffle` (`EXCLUDED_SUBTITLE`) under the title. `SourceRow` grew an
   optional `subtitle: String?` parameter rendered in `caption textSecondary`.

4. **Accessibility (NFR-8).** The switch keeps its existing description; the row
   description is now `listOfNotNull(title, count, subtitle).joinToString(", ")`,
   so an excluded album reads "…, Not in Shuffle". The explainer is plain text
   above the list, so VoiceOver reads it before the first row.

5. **Spec updated** (behavior of FR-37 unchanged):

## Deviations / decisions

- **`footnote` → `caption` for the explainer.** The brief asked for `footnote
  textSecondary`, but the §5.4 type scale has no `footnote` token and §5.4 is
  outside this WP's scope guard, so the explainer uses the smallest existing
  style, `caption textSecondary`. If a `footnote` token is wanted it should be a
  spec decision in §5.4, not a one-off here.
- **Gap as a node, not padding** (see 1 above) — required for the layout test to
  measure the real edge-to-edge gap; visually identical.
- Test lookups inside the clickable row use `useUnmergedTree = true` because
  `clickable` merges descendant `Text` nodes into the row's semantics node.
